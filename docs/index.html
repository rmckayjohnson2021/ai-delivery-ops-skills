Recommended flow

Use the smallest useful artifact first, then add evaluation and governance as risk grows.

1 Phased PRD Align problem, users, scope, phases, and success criteria.
2 Prototype spike Reduce uncertainty before committing to the full build.
3 Evaluation plan Define baselines, metrics, rubrics, and claim boundaries.
4 Governance review Check oversight, auditability, privacy, access, and cost controls.
5 Implementation handoff Convert the decision trail into slices, interfaces, tests, and rollout notes.

Copy/install commands

Use the skills locally

Copy selected skills into your local Codex skills directory. These commands assume the repo is cloned at C:\Dev\repos\ai-delivery-ops-skills.

Open install guide
Install all MVP skills 
$repo = "C:\Dev\repos\ai-delivery-ops-skills"
$skills = "$env:USERPROFILE\.codex\skills"

New-Item -ItemType Directory -Force -Path $skills | Out-Null
Copy-Item -Recurse -Force "$repo\skills\*" $skills
Install one skill 
$repo = "C:\Dev\repos\ai-delivery-ops-skills"
$skills = "$env:USERPROFILE\.codex\skills"

New-Item -ItemType Directory -Force -Path $skills | Out-Null
Copy-Item -Recurse -Force "$repo\skills\phased-prd-builder" "$skills\phased-prd-builder"
Validate the repo 
python scripts\validate_skills.py
