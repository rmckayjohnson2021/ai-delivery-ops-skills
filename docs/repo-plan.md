# Repository Plan

## Purpose

`ai-delivery-ops-skills` is a public portfolio repo that captures reusable planning and governance methods for AI delivery work. It is intentionally artifact-first: the repo helps teams create PRDs, spike plans, implementation handoffs, evaluation plans, and governance reviews.

## Audience

- Product managers shaping AI workflow ideas.
- Engineers preparing implementation-ready handoffs.
- AI delivery leads who need quality, cost, and risk criteria before a build.
- Portfolio reviewers who want to see repeatable delivery practice across projects.

## MVP Structure

The MVP uses plain Markdown so the repo remains easy to inspect and copy:

- `skills/` contains reusable Codex-style skill instructions.
- `templates/` contains starter artifact formats.
- `docs/` explains positioning, scope, and roadmap.
- `examples/` demonstrates how the skills apply to a realistic AI workflow.

## Design Principles

- Make rough requirements actionable without overclaiming certainty.
- Keep AI delivery measurable through evals, rubrics, and case-level reporting.
- Include governance early instead of after implementation.
- Separate portfolio examples from production claims.
- Preserve clear boundaries between companion repos.

## MVP Completion Criteria

- Five starter skills exist and have clear activation boundaries.
- Each skill maps to a template artifact.
- README explains how the repo complements the incident triage and cost gateway projects.
- Example artifact demonstrates a realistic cross-skill flow.
- Repo can be initialized and pushed publicly without secrets or generated clutter.
